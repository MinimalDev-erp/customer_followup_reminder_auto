Customer Follow-up Reminder Automation

This module helps you automatically send customer follow-up reminders using scheduled cron jobs. It is ideal for CRM teams and businesses that want to ensure no customer follow-up is missed.

Key Features

  • Automatic follow-up reminders using cron
  • Configurable follow-up days
  • Dynamic message templates using {{ }} variables
  • Works with Customers and CRM Leads
  • No external API dependency
  • Clean and easy configuration

How It Works

  1. Create a follow-up reminder configuration
  2. Select the target model (Customer or CRM Lead)
  3. Define after how many days the reminder should be sent
  4. Write a dynamic reminder message
  5. The system automatically processes reminders daily

Example Message

Hello {{name}}, this is a reminder regarding your recent interaction with us.

Compatible Odoo Versions

  • Odoo 16

Use Cases

  • CRM follow-ups
  • Customer engagement reminders
  • Sales lead follow-up automation
